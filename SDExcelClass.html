SDExcelClass

Control OLE para generacion de archivos Excel sin Microsoft Excel — SD Digitales 2026

Instalacion Template Uso basico Referencia API Constantes Deployment

Descripcion

SDExcelClass es un wrapper Clarion que replica la API de MSExcelClass / MSOfficeClass de Softmasters, pero utiliza SDExcelCtrl — un control COM OLE basado en ClosedXML 0.97.0 — en lugar de Microsoft Excel.

  • No requiere Microsoft Excel instalado.
  • Genera archivos .xlsx nativos via ClosedXML.
  • Usa OLE estandar de Clarion: Window $ Control{'Metodo(args)'}.
  • No requiere UltimateCOM ni templates de terceros.
  • Compatible con Clarion 11 (x86).

Instalacion

1. Archivos Clarion

Copiar a la carpeta LibSrc\Win de Clarion (p.ej. C:\Clarion11\LibSrc\Win\):

  • SDExcelClass.inc — declaracion de la clase
  • SDExcelClass.clw — implementacion

2. Template

Copiar SDExcelClass.tpl a la carpeta de templates de Clarion (p.ej. C:\Clarion11\Template\) y registrar en el IDE via Tools → Template Registry → Register.

3. DLLs de dependencia

Copiar los siguientes 18 archivos al mismo directorio que el .EXE de la aplicacion:

Origen: SDExcelCtrl\bin\Release\net472\win-x86\

Binding redirect requerido: Cada .EXE de la aplicacion necesita un archivo .exe.config con el siguiente redirect para System.Numerics.Vectors: 
<configuration>
  <runtime>
    <assemblyBinding xmlns="urn:schemas-microsoft-com:asm.v1">
      <dependentAssembly>
        <assemblyIdentity name="System.Numerics.Vectors"
            publicKeyToken="b03f5f7f11d50a3a" culture="neutral"/>
        <bindingRedirect oldVersion="0.0.0.0-4.1.4.0" newVersion="4.1.4.0"/>
      </dependentAssembly>
    </assemblyBinding>
  </runtime>
</configuration>
Importante: El proyecto Clarion debe compilarse como x86. SDExcelCtrl.dll es un ensamblado .NET x86 (ClosedXML no soporta Any CPU en este escenario).

Uso del template

Extension global (SDExcelGlobal)

Agregar la extension SD Excel Extension Global en el nodo Global de la aplicacion. Esto:

  • Incluye SDExcelClass.inc automaticamente.
  • Declara la variable global SDExcel SDExcelClass.

Control OLE en la ventana (SDExcelControl)

En la ventana donde se va a usar Excel, agregar el control SD Excel - SDExcelClass desde el panel de controles. Esto inserta un control OLE invisible (1x1) y cablea automaticamente las propiedades Window y Control del objeto.

Codigo de inicializacion (SDExcelInit)

En la seccion CODE de la ventana, antes de llamar a cualquier metodo, insertar el embed SDExcelInit:

CODE
  SDExcel.Init(SELF,?SDExcel)  ! Activa el control COM
Nota: Init() asigna la ventana y el control, luego llama a Start() que ejecuta PROP:Language y PROP:Create para activar el COM. Debe llamarse despues de que la ventana este abierta.

Codigo de cierre (SDExcelKill)

Al cerrar la ventana, insertar el embed SDExcelKill:

SDExcel.Kill()  ! Desactiva el control COM

Uso basico

! Crear un archivo Excel nuevo
SDExcel.CreateFile()

! Seleccionar celda A1 y escribir un valor
SDExcel.Select('A1')
SDExcel.Assign('Hola Mundo')

! Escribir por posicion (fila, columna)
SDExcel.Assign(2, 1, 'Segunda fila')

! Aplicar formato
SDExcel.SetNumberFormat('#,##0.00')
SDExcel.SetHAlignment(SDExcel:Center)
SDExcel.SetColumnWidth('A', 25)

! Guardar
SDExcel.Save('C:\Temp\Reporte.xlsx')

! Cerrar el workbook
SDExcel.Close(0)

Trabajo con hojas

! Agregar una segunda hoja
SDExcel.AddSheet(1)

! Seleccionar hoja por numero (1-based)
SDExcel.SelectSheet(2)

! Renombrar la hoja activa
SDExcel.SetSheetName(2, 'Detalle')

! Seleccionar hoja por nombre
SDExcel.SelectSheetByName('Detalle')

Lectura de celdas

MiVariable = SDExcel.Read()            ! Celda seleccionada
MiVariable = SDExcel.Read('B5')        ! Por rango
MiVariable = SDExcel.Read(3, 2)        ! Por posicion (fila, columna)

Nota crítica: Build All en Clarion

Después de actualizar SDExcelClass.inc o SDExcelClass.clw, siempre usar Build → Build All (recompilación completa) en el IDE Clarion — nunca Build incremental.

Clarion mantiene la VMT (Virtual Method Table) de la clase por módulo compilado. Si se agrega, elimina o reordena cualquier método en el INC y el proyecto se compila de forma incremental, los módulos que llaman a SDExcel quedan con una VMT desactualizada. El resultado es un GPF en tiempo de ejecución: las llamadas a métodos aterrizan en la función equivocada, con parámetros del stack que no corresponden al método invocado.

Regla: cambio en INC/CLW → ConvertToAnsi.ps1 → Build All en cada app que use SDExcelClass.

Deployment

Para distribuir una aplicacion que usa SDExcelClass:

  1. Incluir los 18 DLLs listados en la seccion Instalacion junto al .EXE.
  2. Crear un .exe.config para cada EXE con el binding redirect de System.Numerics.Vectors (ver seccion Instalacion).
  3. El control usa COM sin registro (Registration-Free COM) via manifest embebido en SDExcelCtrl.dll. No es necesario ejecutar regasm ni tener permisos de administrador.
  4. El proyecto Clarion debe compilarse para x86.
  5. No se requiere .NET Framework adicional: el runtime es net472 (incluido en Windows 10/11).
